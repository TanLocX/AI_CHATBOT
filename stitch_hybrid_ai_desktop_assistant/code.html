How do I use OCR to extract text from an image?

smart_toy

To extract text from an image using this app, follow these steps:

  1. Click the attachment icon (clip or camera) below.
  2. Select your image file from your system.
  3. Choose the "OCR Scan" option from the context menu.

I will then process it using Tesseract and return the extracted text directly in our chat.

PYTHON 
import pytesseract
from PIL import Image

# Basic OCR example
text = pytesseract.image_to_string(Image.open('sample_image.png'))
print(text)
